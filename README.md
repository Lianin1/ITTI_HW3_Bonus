# 🚀 HW3_Bonus 互動式留言板



## ✨ 核心功能

* **發表評論**：使用者可以輸入姓名和留言內容，並提交表單。
* **即時顯示**：新的留言會立刻被加到留言列表的最上方，無需重新整理頁面。
* **資料持久化**：使用瀏覽器的 `localStorage` 技術，留言會被保存在使用者的本機上。
* **(獨特功能)**：即使**關閉瀏覽器或重新整理頁面**，之前留下的評論依然會被載入並顯示。
* **現代化 UI**：
    * 留言板在頁面中垂直和水平置中。
    * 背景採用黑白斜向漸層。
    * 留言板本身具有「毛玻璃」的半透明質感。
    * 所有互動元素（按鈕、輸入框）均為灰黑白風格。

---

## 🛠️ 使用技術

* **HTML5**：負責網站的基本結構和內容（表單、列表區域）。
* **CSS3**：
    * 負責所有樣式、美化和排版。
    * 使用 **Flexbox** 來達成頁面置中。
    * 使用 `linear-gradient` 建立漸層背景。
    * 使用 `backdrop-filter: blur()` 製作毛玻璃效果。
* **JavaScript (ES6+)**：
    * 處理 DOM 操作（動態新增/讀取 HTML 元素）。
    * 監聽 `submit` 事件來抓取表單資料。
    * 使用 `localStorage` API ( `setItem` 和 `getItem` ) 來儲存和讀取留言資料。
    * 使用 `JSON.stringify` 和 `JSON.parse` 來在陣列和字串之間轉換資料。
